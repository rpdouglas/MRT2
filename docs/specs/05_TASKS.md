# 📐 Feature Spec: Tasks & Habits (The Ledger)

**Status:** Live (v2.1)
**Context:** High-density professional task management with AI action routing.

## 1. Overview
A streamlined interface for managing one-time tasks and recurring habits. Rebranded from "Quests" to "Tasks" to align with a professional recovery ledger aesthetic.

## 2. Smart Tabs (Routing Logic)
The system segregates tasks into four distinct lanes:
1. **This Week:** Active tasks where `dueDate` is less than 7 days from today AND `source` == 'manual'.
2. **Later:** Tasks where `dueDate` is exactly 7 days or more in the future AND `source` == 'manual'.
3. **Action Plan:** Tasks where `source` == 'ai'. This lane is reserved for growth items generated by the Compass (Workbooks) or Analysis Wizard (Journals).
4. **Log (History):** All tasks where `status` == 'completed' or where a recurring task was completed *today*. 
    * **Performance:** This view is virtualized using `react-virtuoso` and grouped hierarchically by Year -> Month to handle thousands of completed habits without UI lag.

## 3. Data Structure
**Collection:** `tasks`
| Field | Type | Description |
| :--- | :--- | :--- |
| `source` | string | 'manual' \| 'ai' (Determines tab routing) |
| `category` | string | 'Recovery', 'Health', 'Work', 'Life' |
| `priority` | string | 'High', 'Medium', 'Low' |
| `currentStreak`| number | Cumulative consecutive completions |
| `dueDate` | Timestamp | Next scheduled deadline |
| `recurrence` | Map | The full `RecurrenceConfig` object (type, interval, dayOfWeek, etc.) governing repetition. |

## 4. Technical Logic
* **Optimistic UI:** Toggle actions use React Query `onMutate` for zero-latency feedback.
* **Smart Reset:** Recurring tasks missed yesterday are automatically moved to "Today" with a streak penalty, preventing "schedule debt."
* **Future Task Safety:** If a user attempts to complete a task whose `dueDate` is strictly in the future, the optimistic UI update is intercepted by a Headless UI modal requiring explicit confirmation. This prevents accidental completion of future requirements.
