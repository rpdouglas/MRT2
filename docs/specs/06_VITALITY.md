# 📐 Feature Spec: Vitality (Health)

**Status:** Live (v1.0)
**Context:** Somatic regulation and basic health logging.

## 1. Overview
Logs for Movement, Nutrition, and Breathwork. These are stored as **Journal Entries** with special tags (`#Vitality`, `#Movement`).

## 2. Features
* **Breathwork:** 4-7-8 Breathing Timer. Auto-logs duration.
* **Logging:** Simple forms for Food/Exercise.
